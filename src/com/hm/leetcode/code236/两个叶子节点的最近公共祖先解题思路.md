# 二叉树中两个叶子节点的最近公共祖先 解题文档

## 一、题目描述

给定一棵二叉树，以及树中的两个节点 `p`、`q`（本题特指两个**叶子节点**），找出它们的**最近公共祖先**（LCA, Lowest Common Ancestor）。

最近公共祖先定义为：在树 `root` 中，**同时拥有 `p` 和 `q` 作为后代**（一个节点也可以是它自己的后代）的、**深度最大**的那个节点。

> 本题等价于 LeetCode 236「二叉树的最近公共祖先」，只是把 `p`、`q` 限定为叶子节点。

**示例**（基于下面这棵树）：

```
           3
         /   \
        5     1
       / \   / \
      6   2 0   8
         / \
        7   4
叶子节点：6, 7, 4, 0, 8
```

| 输入 (p, q) | 输出 | 说明 |
|-------------|------|------|
| `(7, 4)` | `2` | 同属节点 2 的左右孩子 |
| `(6, 4)` | `5` | 都在 5 的子树里，6 是 5 的左孩子，4 在 5 的右子树深处 |
| `(6, 8)` | `3` | 分别落在根的左、右两侧 |
| `(0, 8)` | `1` | 都在右子树 1 之下 |

**链接：** https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/

---

## 二、核心观察

1. **“叶子节点”不是特殊情况。** 求两个叶子的 LCA 和求任意两个节点的 LCA 用的是同一套逻辑——叶子只是“没有孩子”的普通节点，后代集合为空，算法无需任何额外分支。
2. **LCA 的判定特征：** 对某个节点 `root`，如果 `p`、`q` **分别**出现在它的左子树和右子树，那么 `root` 就是它们的 LCA；如果两者都在同一侧，LCA 一定更深，在那一侧继续找。
3. **自底向上 vs 自顶向下：** 递归后序天然“自底向上”回溯，第一个让左右子树各命中一个目标的节点就是答案；而求路径法是“自顶向下”记录轨迹，再比较两条路径的最后一个公共点。

---

## 三、两种解法

### 解法一：递归后序遍历（推荐）

**思路：**

定义 `lowestCommonAncestor(root, p, q)`：在以 `root` 为根的子树中查找 `p`、`q`，返回它们的 LCA；若都不在该子树则返回 `null`。

1. **递归出口：** `root` 为空，或 `root` 本身就是 `p` 或 `q`，直接返回 `root`。
2. 分别在**左子树**、**右子树**递归查找，得到 `left`、`right`。
3. 若 `left`、`right` **都非空**，说明 `p`、`q` 分居 `root` 两侧，当前 `root` 即为 LCA。
4. 否则哪一侧非空就把哪一侧上抛（两个目标都在同侧，或都不存在）。

**关键代码：**

```java
public static TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) {
        return root;
    }
    TreeNode left = lowestCommonAncestor(root.left, p, q);
    TreeNode right = lowestCommonAncestor(root.right, p, q);
    if (left != null && right != null) {
        // p、q 分居 root 两侧，当前 root 就是最近公共祖先
        return root;
    }
    // 都在同一侧（或都不在），返回非空的一侧
    return left != null ? left : right;
}
```

- **时间复杂度：** O(n)，每个节点最多访问一次。
- **空间复杂度：** O(h)，递归栈深度，`h` 为树高，最坏（链状树）退化为 O(n)。
- **优点：** 一次遍历、代码极简、不需要额外存储。
- **缺点：** 自底向上回溯逻辑初看不直观；隐含假设 `p`、`q` 都在树中（题目通常保证）。

---

### 解法二：两次路径查找

**思路：**

1. 用 DFS 分别求出 `root → p`、`root → q` 的**路径**（从根到目标的节点序列）。
2. 同步遍历两条路径，**最后一个相同的节点**就是 LCA。

**关键代码：**

```java
public static TreeNode lowestCommonAncestorByPath(TreeNode root, TreeNode p, TreeNode q) {
    List<TreeNode> pathP = new ArrayList<>();
    List<TreeNode> pathQ = new ArrayList<>();
    if (!findPath(root, p, pathP) || !findPath(root, q, pathQ)) {
        return null; // 有节点不在树中
    }
    TreeNode lca = null;
    int n = Math.min(pathP.size(), pathQ.size());
    for (int i = 0; i < n; i++) {
        if (pathP.get(i) == pathQ.get(i)) {
            lca = pathP.get(i);
        } else {
            break;
        }
    }
    return lca;
}

// DFS 求 root 到 target 的路径，找到返回 true 并写入 path（含回溯）
private static boolean findPath(TreeNode root, TreeNode target, List<TreeNode> path) {
    if (root == null) {
        return false;
    }
    path.add(root);
    if (root == target) {
        return true;
    }
    if (findPath(root.left, target, path) || findPath(root.right, target, path)) {
        return true;
    }
    path.remove(path.size() - 1); // 回溯
    return false;
}
```

- **时间复杂度：** O(n)，两次遍历。
- **空间复杂度：** O(n)，存放两条路径（外加 O(h) 递归栈）。
- **优点：** 思路直观，路径本身可复用（如求两节点距离 = 两路径长度之和 − 2×LCA 深度）。
- **缺点：** 需要额外存路径，常数更大；要遍历两遍。

## 四、两种解法对比

| 解法 | 核心思路 | 时间 | 空间 | 优点 | 缺点 |
|------|----------|------|------|------|------|
| 一、递归后序 | 自底向上，左右各命中一个则当前是 LCA | O(n) | O(h) | 一遍、极简、省空间 | 回溯逻辑不直观 |
| 二、路径查找 | 求两条根到叶路径，取最后公共点 | O(n) | O(n) | 直观、路径可复用 | 存路径、遍历两遍 |

---

## 五、易错点总结

1. **比较节点用引用而非值。** 路径法比较时应判断 `pathP.get(i) == pathQ.get(i)`（同一个节点对象）。若树中存在重复值，按 `val` 比较会出错。
2. **路径回溯不能漏。** `findPath` 在左右子树都没找到时，必须把当前节点从 `path` 中弹出，否则路径会混入无关分支。
3. **目标不在树中。** 解法一隐含假设 `p`、`q` 存在；若不保证，应改用“同时记录是否找到”的变体，或用解法二（`findPath` 返回 `false` 时直接判 `null`）。
4. **一个是另一个的祖先时。** LCA 定义允许节点是自身的后代——本题两节点都是叶子，不会出现此情形，但写通用 LCA 时解法一的出口 `root == p || root == q` 正是为此而设，不可省。
5. **空树 / 单节点。** `root` 为空直接返回 `null`；务必保留递归出口。
