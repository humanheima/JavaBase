# LeetCode 111. 二叉树的最小深度（Minimum Depth of Binary Tree）解题文档

> 注：题目链接对应的是 **第 111 题**（minimum-depth-of-binary-tree），目录命名为 `code111`。

## 一、题目描述

给定一个二叉树，找出其**最小深度**。最小深度是从根节点到**最近叶子节点**的最短路径上的**节点数量**。

**说明：** 叶子节点是指没有子节点的节点。

**示例：**

| 输入（层序） | 输出 | 说明 |
|--------------|------|------|
| `[3,9,20,null,null,15,7]` | `2` | 根 3 → 叶子 9，最短 |
| `[2,null,3,null,4,null,5,null,6]` | `5` | 右斜链，唯一叶子在最底层 |
| `[]` | `0` | 空树 |
| `[1]` | `1` | 单节点即叶子 |

**链接：** https://leetcode.cn/problems/minimum-depth-of-binary-tree/

---

## 二、核心观察

1. **最小深度的终点必须是「叶子」**——没有左右孩子的节点。这是和「最大深度」最大的区别。
2. **关键陷阱**：当一个节点**只有一个孩子**时，不能简单套用 `min(左, 右) + 1`。
   - 例如根节点只有右孩子：`左子树深度 = 0`，`min(0, 右) + 1 = 1` 会把这个**内部节点**误判成叶子，得到错误的最小深度。
   - 正确做法：缺哪边就**只往存在的那一侧**走。
3. 「最大深度」没有这个问题，因为取 `max` 时空子树的 0 不会成为较大值；但「最小深度」取 `min`，空子树的 0 会污染结果，必须特判。

---

## 三、两种解法

### 解法一：递归 DFS

**思路：**
1. 空节点返回 0。
2. 叶子节点（左右都空）返回 1。
3. 只有右子树 → `minDepth(right) + 1`；只有左子树 → `minDepth(left) + 1`。
4. 左右子树都在 → `min(左, 右) + 1`。

```java
public int minDepth(TreeNode root) {
    if (root == null) {
        return 0;
    }
    if (root.left == null && root.right == null) {
        return 1;
    }
    if (root.left == null) {
        return minDepth(root.right) + 1;
    }
    if (root.right == null) {
        return minDepth(root.left) + 1;
    }
    return Math.min(minDepth(root.left), minDepth(root.right)) + 1;
}
```

- **时间复杂度：** O(n)，每个节点访问一次
- **空间复杂度：** O(h)，递归栈深度（树高），最坏退化为链表时 O(n)
- **优点：** 代码简洁，自然表达递归结构
- **缺点：** 必须遍历完整棵树才能确定最小值；最坏栈深 O(n)

---

### 解法二：迭代 BFS（层序遍历）

**思路：**
1. 用队列按层遍历，深度从 1 开始计数。
2. **遇到的第一个叶子节点**，它所在的层号就是最小深度——因为 BFS 逐层推进，最先触底的叶子必然在最浅层。
3. 找到即提前返回，无需遍历剩余节点。

```java
public int minDepthBfs(TreeNode root) {
    if (root == null) {
        return 0;
    }
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 1;
    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            if (node.left == null && node.right == null) {
                return depth;   // 第一个叶子所在层即最小深度
            }
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        depth++;
    }
    return depth;
}
```

- **时间复杂度：** O(n) 最坏；通常因提前返回而更快
- **空间复杂度：** O(n)，队列最多存一层的节点
- **优点：** 找到最浅叶子即停，平均效率高，**无需访问深层节点**
- **缺点：** 需要额外的队列空间

## 四、两种解法对比

| 解法 | 核心思路 | 时间 | 空间 | 优点 | 缺点 |
|------|----------|------|------|------|------|
| 一、递归 DFS | 缺孩子时只走非空侧，否则取 min | O(n) | O(h) | 简洁 | 必遍历整棵树 |
| 二、迭代 BFS | 逐层找第一个叶子即停 | O(n) | O(n) | 可提前返回 | 队列开销 |

---

## 五、易错点总结

1. **单孩子陷阱（最核心）**：节点只有一个孩子时，不能用 `min(左, 右) + 1`，否则空子树的 0 会让内部节点被当成叶子。必须对「左空」「右空」分别特判。
2. **叶子定义**：最小深度的终点是「无左右孩子」的节点，不是「任意空指针」。
3. **空树返回 0、单节点返回 1**：边界要处理对。
4. **与最大深度区分**：最大深度可以直接 `max(左, 右) + 1` 无需特判，最小深度不行——这是两题最容易混淆的地方。
5. **BFS 深度初值**：根节点算第 1 层，`depth` 应从 1 开始；遇到第一个叶子立即返回。
